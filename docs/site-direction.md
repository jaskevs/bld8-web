# Site direction

Status: to be decided during visual-direction work.

Decide and record:

- Typefaces and fallback stacks.
- Type scale, spacing scale, colour, radius and grid.
- Home/Work/About layouts at narrow and wide widths.
- Focus, hover, navigation and reduced-motion behaviour.
- One primary theme; a second theme and signature interaction are optional depth.

Use `src/styles/tokens.css`, `reset.css`, `globals.css` and `motion.css` when the
design is chosen, with a CSS Module for each component as needed. Do not treat
this document as approved visual design; attach the real design evidence later.
